# Модуль комментариев – система управления учебными проектами

## Описание
Модуль предоставляет REST API для управления комментариями к задачам.
Особенности:
- Вложенные ответы (комментарии могут иметь родительские комментарии).
- Мягкое удаление (комментарий помечается как удалённый, но не стирается из БД).
- Уведомление автора задачи при добавлении нового комментария.
- Временное окно для редактирования (10 минут после создания).
- Запрет комментирования закрытых задач.
